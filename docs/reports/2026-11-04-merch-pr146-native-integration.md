# PR #146: перенос улучшений в native ePharm

## Проверенная исходная точка

PR #146 `bd58fdbe9ca574031f9991eff0fdfc55e1d12d39` основан на main
`0c9086c68523a459ca462b9194f91f30a0a5cc2a`. Перед работой production backend/frontend
подтвердили v0.2.4 и этот же commit. РПС выключен, native merch включён.

Исходный PR меняет пять patch/report-файлов для отдельного CRM (`OperationalTasksPage.jsx`,
`merchRedesign.css`, RPC). Он не меняет deployable native React. Поэтому простой merge
сохранил бы main, но не обновил бы рабочий `/merch/tasks`. Исходный commit и его пять
артефактов сохранены; legacy patches не применяются к live CRM/ePharm.

## Карта нового и сохранённого

| Изменение PR                      | Native результат                                      | Сохранённый контракт                                       |
| --------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------- |
| Компактная шапка и единая таблица | `MerchTasksPage`, текущие ePharm tokens               | Все колонки и действия текущей очереди                     |
| Создание справа                   | Правый `Modal`, сгруппированные текущие поля и сводка | Single/bulk intent ID, валидация, финансовое право         |
| Карточка проверки справа          | Тот же `MerchTaskDetail` внутри панели                | can\*, attempt/version CAS, причины, история и комментарии |
| Полки и тип задания               | Существующий native шаблон в правой панели            | Серверный каталог шаблонов, режим полок, снимок, сроки     |
| Доступные действия при прокрутке  | Закреплённые действия формы и закрытие в шапке        | Pending-запрос не теряется при Escape/close                |
| Метрики и очереди                 | Существующие scoped queue/search/paging               | Глобальные счётчики не выдумываются из 20 строк страницы   |
| QR/исполнитель                    | Существующие native `/tasks/staff` и `/learn`         | POSM issuer/ACK, private media, личная привязка            |

Не возвращаются legacy RPC, старые проверки роли, общий месячный код или запись в
retired CRM database. Existing monthly visit, stock/video/instruction flows, exported Excel,
собственная очередь, отмена/блокировка и отдельные права сохраняются на действующих API.
Запрет самоприёмки и удержание спорных начислений остаются серверными правилами.

## Проверки и выпуск

Локально прошли 1088 unit, TypeScript, ESLint и build. На собранных файлах прошли
63 browser-проверки; 8 опциональных сценариев с отдельным интеграционным backend
локально не запускались. Новые browser-проверки работают
на собранных файлах с полностью синтетическими API: desktop 1280/1440/1920, панели 390,
независимая прокрутка, доступные действия, nested Escape/focus и сохранённые операции.
Старый desktop min-width HQ shell не маскируется CSS; мобильные QR/learn остаются отдельными.

Точные результаты CI и итоговый merged commit фиксируются в PR. Разрешён только
штатный frontend-only release с проверенным source/image и backup/rollback: работающий
backend v0.2.4, Caddy, DB и файловые mounts не пересоздаются. РПС не включается.
Отложенный Sentry PR #144 не входит в этот выпуск и остаётся отдельно до авторизации.
До фактической проверки deployment этот отчёт не означает, что prod обновлён.
