# Качество классификации ACC для триггеров рекомендаций

Источник: предоставленный файл `Каталог АСС.xlsx`, лист `Лист1` (25 817 строк после заголовка, включая 4 полностью пустые). Проверка выполнена 2026-10-06. Гранулярность импорта — пара `WARE_ID` + штрихкод; цены, остатки, названия и прочие поля файла в триггерах не используются. Исходный Excel и подготовленный SQL не хранятся в Git.

| Проверка | Результат | Влияние |
| --- | ---: | --- |
| Валидные отображения `WARE_ID` + штрихкод длиной 8–14 цифр | 28 872 | Потенциальная база для точного поиска по скану. |
| Различные штрихкоды | 28 610 | Единица покрытия кассовых сканов. |
| Штрихкоды с несколькими `WARE_ID` | 230 (0,8%) | Групповой триггер не срабатывает: нельзя выбрать препарат наугад. |
| Однозначные штрихкоды | 28 380 | Только они участвуют в групповых/МНН-правилах. |
| Однозначные штрихкоды с группой | 22 367 (78,8%) | Остальные не могут запускать правило группы. |
| Однозначные штрихкоды с подгруппой и родительской группой | 22 271 (78,5%) | Подгруппа без родительской группы не считается самостоятельной. |
| Однозначные штрихкоды с содержательным МНН | 14 960 (52,7%) | `0`, пустые значения и заглушки не могут запускать правило МНН. |
| Различные доступные области | 84 группы, 1 018 подгрупп, 1 370 МНН | Подгруппа идентифицируется вместе с родительской группой. |

У 220 непустых строк нет штрихкода длиной 8–14 цифр; ещё 4 строки полностью пустые. Они не импортируются в таблицу сопоставления. У источника нет надёжного поля «дата актуальности классификации»: даты в некоторых заголовках относятся к августу 2026 года и не доказывают свежесть всех строк на октябрь 2026-го. Владелец подтвердил, что сейчас это единственный источник; регулярной выгрузки/API нет.

Вывод для релиза: инфраструктура и интерфейс новых правил могут быть выпущены с этим явно версионированным снимком, но новые групповые/МНН-правила не следует включать автоматически. Для каждого опубликованного правила нужен осмысленный выбор области и предложений ответственным менеджером. Групповой/МНН-поиск требует именно штрихкод из ACC: внутренний код Standard-N или одно только название не дают надёжного группового совпадения. При неизвестном, неоднозначном или не имеющем нужной классификации штрихкоде новое правило не срабатывает; существующие товарные правила продолжают работать. При следующем файле ACC импортировать новую неизменяемую версию и переключать активный указатель только после проверки покрытия и расхождений.

Воспроизводимая проверка: `tools/prepare-acc-recommendation-catalog.py` и `tools/tests/test_prepare_acc_recommendation_catalog.py`. Пробный импорт в отдельную PostgreSQL 16 подтвердил 28 872 строки, 28 610 различных штрихкодов и атомарное переключение активного снимка.
