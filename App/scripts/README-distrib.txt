==========================================================
  Epharm POSM — клиентский экран + рекомендации для кассы
  Стандарт-Н. БОЕВОЙ режим (смотрит на прод-бэкенд).
==========================================================

ЧТО ЭТО
  Десктоп-приложение для аптечной кассы:
   • показывает на клиентском экране видео-плейлист (управляется из админки);
   • слушает лог кассовой программы Стандарт-Н и при добавлении товара,
     на который заведено правило, показывает попап-рекомендацию
     (замена / кросс-селл) с бонусом фармацевту;
   • зеркалит чек на клиентский экран.

ТРЕБОВАНИЯ
  • Windows 10/11, 64-бит.
  • .NET ставить НЕ нужно — сборка self-contained (рантайм внутри).
  • Для попапов-рекомендаций нужен установленный Стандарт-Н (ДЕМО подойдёт).
    Без него экран и видео работают, но попапов не будет (нечего слушать).

КАК ЗАПУСТИТЬ
  1. Распакуй весь ZIP в любую папку, например  C:\Epharm-POSM
     (распаковывай ЦЕЛИКОМ — рядом с .exe лежат рантайм и libvlc).
  2. Двойной клик по  Запустить.bat
     (он подставляет путь к конфигу и стартует приложение).
  3. Появится клиентский экран с видео. Приложение уже настроено на
     БОЕВОЙ бэкенд — ничего вводить не надо.

ПРОВЕРКА РЕКОМЕНДАЦИЙ (с Стандарт-Н)
  • Запусти Стандарт-Н (АРМ Кассир), добавь в чек товар, на который
    заведено правило (для демо — «Ликопид 10мг таб №10»).
  • Через ~0.5 c всплывёт попап: вкладки «Замена» / «Кросс-селл».
  • Клавиши попапа:  Tab — сменить вкладку,  F9 — принять,  Esc — пропустить.
  • Товар из чека зеркалится на клиентский экран.

ЕСЛИ ЛОГ СТАНДАРТ-Н В НЕСТАНДАРТНОМ МЕСТЕ
  По умолчанию приложение само ищет лог по стандартным путям
  (C:\Standart-N\... и C:\Standart-N_DEMO\...). Если у тебя другой путь —
  открой Запустить.bat в блокноте и добавь строку ПЕРЕД "start":
      set "EPHARM_LOG_PATH=C:\путь\к\zkassa.log"

ЛОГИ ПРИЛОЖЕНИЯ
  Рабочий стол → customerdisplay.log (там видно, какой лог слушается,
  какие строки считаны, какие рекомендации пришли).

ЗАМЕТКИ
  • Конфиг — файл posm.json рядом с .exe (адрес бэкенда, ключ устройства,
    id аптеки). Менять не нужно — он уже боевой.
  • Видео в плейлисте управляется из админки и подхватывается без
    перезапуска (опрос раз в ~2 минуты).
  • Закрыть: Alt+F4 в окне приложения.
